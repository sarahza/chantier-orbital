📋 Sans robot : commandes à copier ou pack de données
  1. Dans ton monde, active les commandes (triches).
  2. Place-toi à l'endroit voulu : la construction apparaît juste devant toi (2 blocs plus loin, côté x et z positifs).
  3. Java : télécharge le pack de données, mets le fichier .zip dans le dossier datapacks de ton monde, tape /reload, puis /function leftcontrol:construire.
  4. Bedrock (ou Java) : copie les commandes une par une dans le chat.
